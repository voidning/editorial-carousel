# 案例：博物学视觉语言拆解

用本 skill 做的第一组图。选题是拆解 Anthropic 三支品牌片（Fable 5 / Fable 5.1 / Opus 5.5）里的博物学美学——为什么一家 AI 公司的广告拍得像 19 世纪的标本图版。

10 页，1080×1440，纯静帧。原始素材是广告片截图，未在仓库内分发。

## 这期验证了什么

- **页型够用**：10 页里用掉 7 种，没有一种是为了凑数硬塞的。
- **字号必须按手机重定**：初版按网页阅读距离设成正文 20 px，实际在手机上只剩 7 pt，偏小。整篇放大约 30%（正文 26 px）后成立——这也是 `references/layout-rules.md` 里那条下限的来源。
- **放大必然溢出**：字号调大后，封面标题撑成三行、第 9 页底稿溢出、第 3 页贴底。三处都靠**减字**而不是缩字号解决。
- **纯文本是硬约束**：文案初版带 markdown，粘贴后符号原样显示。

## 复用方式

版式源码不在本目录。要复刻，直接复制 `assets/base.html`，按上表的页型顺序删减，把文字换掉即可——骨架里的页型编号与这里一一对应。
