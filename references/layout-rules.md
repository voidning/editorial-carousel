# 版式规则

## 字号基准（1080 宽画面，改比例时按比例缩）

| 位置 | 值 | 说明 |
| --- | --- | --- |
| 封面主标题 | 78 px | 一行放不下就手动 `<br>` 断行，别让它自己折 |
| 小节标题 h2 | 54 px | |
| 引文 | 34 px | 衬线，最多两行 |
| 正文 | 26 px | **下限**。低于这个数手机上就吃力 |
| 题记 `.lede` | 28 px | 衬线 —— 跟标题同族，见下节 |
| 条目说明 | 24 px | `.row p` |
| 页脚注 `.note` | 21 px | |
| 栏头 `.kicker` | 19 px | 中文部分要 sans，纯英文才套 `.en`（mono） |
| 图注 `figcaption` | 18 px | |
| 页码 / 页脚 | 17 px | |
| 大字词 | 96 px / 42 px | 西文 + 中文对译 |

行高：正文 1.8，标题 1.3 左右，图注 1.5。

**字号只写在 CSS，不要在标签行内用 `style` 覆盖。** 行内值会让"一个角色一个字号"失去唯一来源：
改一次字号必然漏掉若干处，而漏掉的恰恰是读者看得见的"不统一"。
首期踩过——`.lede` 基准 28 px，第 7 页却在行内写了 20 px，于是那一页的题记**比它下面的正文还小**，
同页之内就能看出层级倒挂。

破例只有一档：**次要信息**（引文出处、版权与来源行）可以比正文低一档（26 → 21 px），到此为止。
要破这一档，先改这条规则，别直接在标签上写。

自检命令行（有输出 = 有行内覆盖，逐条收回到 CSS）：

```bash
grep -o 'style="[^"]*font-size[^"]*"' notes.html
```

## 字体：三个角色，按阅读位置判

| 角色 | 用哪族 | 落在哪 | 怎么认 |
| --- | --- | --- | --- |
| 题记 | 衬线 `--serif` | `h1` `h2` `h3`、`.lede`、大字词 `.word`、引文 `blockquote p` | 紧跟大标题、字号接近标题 → 读者读作**标题的一部分** |
| 正文与说明 | 黑体 `--sans` | 正文 `p`、`.sub`、`.note`、图注 | 在正文流里 → 读者读作**正文的一部分** |
| 数字与英文小标签 | 等宽 `--mono` | 栏头 `.kicker .en`、页码、编号 `.row .no`、色值 `.sw .hex`、纯英文图注 `.en` | 是**标签**，不是句子 |

**按阅读位置判，不要按类名判。** `.lede`（题记）和 `.sub`（正文说明）类名相近，但位置、字号、
读者预期都不同，**不必强行同族** —— 题记跟标题走，说明跟正文走。

### 反馈说"不统一"时，先定位再动手

**判据：这个差异，读者能不能读出一个意思？** 能 → 留（它是层级）；不能 → 统一（它是脏）。

反向的错也犯过：看到「每一张字体好像不统一」，第一反应是把 `.lede` 压成黑体求"统一"，
封面那块衬线体量被切断，整页反而变差，又改了回来。**读者的感知是真的，但他指向的地方
常常不是病灶** —— 别急着改那个承担美感的差异，去找读不出含义的那一处。

**含中文的图注一律黑体。** `figcaption` 原本整条是等宽，而 `SF Mono` 没有 CJK 字形，中文会回退
（macOS 上落到黑体），于是「Fable 5.1 · 」的字距是松的、后面的中文是紧的，**一行里两种节奏**，
读起来是断的。做法：`figcaption` 默认黑体，`figcaption.en` 只给纯英文的型号/编号标注；
其它位置的中文标签加 `.zh` 切回 sans。

一处可以不管的：衬线栈里的中文（`Songti SC`）和西文（`Iowan Old Style`）不是同一族，
78 px 标题里混排能看出差别。这是可接受的 —— 读者读到的是"标题衬线、正文黑体"的层级关系，
不是衬线风格本身。不值得为它换字体。

## 页型选择

| 内容形态 | 用哪一页 |
| --- | --- |
| 一句话结论 + 一张主视觉 | 页型 1 封面 |
| 一段论述 + 一张证据图 | 页型 2（`.media` 让图在剩余空间居中） |
| 三个并列对象 | 页型 3 三联图 + 条目表 |
| 一个需要被记住的术语 | 页型 4 大字词页，一页只讲一个词 |
| 立场、态度、名言 | 页型 5 引文页 |
| 给读者的可复制参数（配色、尺寸、规格） | 页型 6 色板 / 页型 8 术语对照 |
| 字体、材质这类"样板" | 页型 7 `.specimen` |
| 收尾 | 页型 9：关键词 + 一句结语 + 来源 |

页数控制在 8–12 张。低于 8 张撑不住一个选题，高于 12 张没人翻完。

## 留白：只允许两种情况

1. **图片页**：文字在上、图在 `.media` 里上下居中，留白均匀分在图的上下。
2. **文字页**：内容从顶部排下来，末尾用 `.note`（`margin-top:auto` + 上细线）贴底收束。

禁止出现"文字排完、图被 `margin-top:auto` 顶到最底、中间空一大块"——看起来像没排完。
如果内容不够撑满，加一段有信息量的注而不是拉大行距。

## 断行

- 中文标题手动 `<br>` 断行，断在语义停顿处（逗号后），两行长度尽量接近。
- 发现标题折成三行 = 字号过大或字太多，先删字（"一家""真的"这类虚词最先删）。
- 正文不要手动断行，交给浏览器。

## 图片

1. **先压缩**：长边压到 1080–1600，JPEG q82–86。原图 6 MB 的接触表压完约 0.5 MB。
   ```bash
   sips -s format jpeg -s formatOptions 84 --resampleWidth 1600 in.png --out out.jpg
   ```
2. **有原始比例的图不要设固定高度**（会裁掉内容）。要裁切时先想清楚裁掉的部分是否可弃——
   接触表、四格拼图这类信息型图片一律保持完整。
3. 需要统一观感时，用 `object-fit:cover` + 固定高度做横条（只适合本身可裁的纹理型图片）。
4. 每张图都要有图注，说清它在证明什么，而不是重复正文。

## 出图后自检清单

逐张看缩略图（`--resampleWidth 620`），每张过一遍：

- [ ] 底部有没有被裁掉的字（溢出页面的征兆）
- [ ] 有没有中部空洞（> 200 px 的空白带）
- [ ] 标题有没有折成三行或断在奇怪的位置
- [ ] 图片有没有被裁掉主体
- [ ] 页码与总页数对不对
- [ ] 同一信息（栏目名、来源）表述前后一致
- [ ] 含中文的地方没有被套等宽（表现为一行里西文疏、中文紧）
- [ ] 行内 `style` 里没有 `font-size`（`grep -o 'style="[^"]*font-size[^"]*"' notes.html` 应无输出）
- [ ] 同一角色的字号跨页一致（重点查题记 `.lede`：全篇应为一个值）

缩略图上出现的灰块、条纹多半是 JPEG 压缩伪影，判断 1px 级细节要回原图裁局部看：

```bash
sips -s format jpeg --cropToHeightWidth 300 1080 --cropOffset 830 0 out/09.png --out /tmp/crop.jpg
```
