# 版式规则

## 字号基准（1080 宽画面，改比例时按比例缩）

| 位置 | 值 | 说明 |
| --- | --- | --- |
| 封面主标题 | 78 px | 一行放不下就手动 `<br>` 断行，别让它自己折 |
| 小节标题 h2 | 54 px | |
| 引文 | 34 px | 衬线，最多两行 |
| 正文 | 26 px | **下限**。低于这个数手机上就吃力 |
| 条目说明 | 24 px | `.row p` |
| 页脚注 `.note` | 21 px | |
| 栏头 `.kicker` | 19 px | 中文部分要 sans，纯英文才套 `.en`（mono） |
| 图注 `figcaption` | 18 px | |
| 页码 / 页脚 | 17 px | |
| 大字词 | 96 px / 42 px | 西文 + 中文对译 |

行高：正文 1.8，标题 1.3 左右，图注 1.5。

## 页型选择

| 内容形态 | 用哪一页 |
| --- | --- |
| 一句话结论 + 一张主视觉 | 页型 1 封面 |
| 一段论述 + 一张证据图 | 页型 2（`.media` 让图在剩余空间居中） |
| 三个并列对象 | 页型 3 三联图 + 条目表 |
| 一个需要被记住的术语 | 页型 4 大字词页，一页只讲一个词 |
| 立场、态度、名言 | 页型 5 引文页 |
| 给读者的可复制参数（配色、尺寸、规格） | 页型 6 色板 / 页型 8 术语对照 |
| 字体、材质这类"样板" | 页型 7 `.specimen` |
| 收尾 | 页型 9：关键词 + 一句结语 + 来源 |

页数控制在 8–12 张。低于 8 张撑不住一个选题，高于 12 张没人翻完。

## 留白：只允许两种情况

1. **图片页**：文字在上、图在 `.media` 里上下居中，留白均匀分在图的上下。
2. **文字页**：内容从顶部排下来，末尾用 `.note`（`margin-top:auto` + 上细线）贴底收束。

禁止出现"文字排完、图被 `margin-top:auto` 顶到最底、中间空一大块"——看起来像没排完。
如果内容不够撑满，加一段有信息量的注而不是拉大行距。

## 断行

- 中文标题手动 `<br>` 断行，断在语义停顿处（逗号后），两行长度尽量接近。
- 发现标题折成三行 = 字号过大或字太多，先删字（"一家""真的"这类虚词最先删）。
- 正文不要手动断行，交给浏览器。

## 图片

1. **先压缩**：长边压到 1080–1600，JPEG q82–86。原图 6 MB 的接触表压完约 0.5 MB。
   ```bash
   sips -s format jpeg -s formatOptions 84 --resampleWidth 1600 in.png --out out.jpg
   ```
2. **有原始比例的图不要设固定高度**（会裁掉内容）。要裁切时先想清楚裁掉的部分是否可弃——
   接触表、四格拼图这类信息型图片一律保持完整。
3. 需要统一观感时，用 `object-fit:cover` + 固定高度做横条（只适合本身可裁的纹理型图片）。
4. 每张图都要有图注，说清它在证明什么，而不是重复正文。

## 出图后自检清单

逐张看缩略图（`--resampleWidth 620`），每张过一遍：

- [ ] 底部有没有被裁掉的字（溢出页面的征兆）
- [ ] 有没有中部空洞（> 200 px 的空白带）
- [ ] 标题有没有折成三行或断在奇怪的位置
- [ ] 图片有没有被裁掉主体
- [ ] 页码与总页数对不对
- [ ] 同一信息（栏目名、来源）表述前后一致
- [ ] 有没有中文被套了 mono（表现为字距突然变大、字重不匀）

缩略图上出现的灰块、条纹多半是 JPEG 压缩伪影，判断 1px 级细节要回原图裁局部看：

```bash
sips -s format jpeg --cropToHeightWidth 300 1080 --cropOffset 830 0 out/09.png --out /tmp/crop.jpg
```
