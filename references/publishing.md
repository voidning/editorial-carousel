# 发布规范（小红书）

## 图片

- 尺寸 **1080×1440（3:4）**，PNG 或 JPEG，单张控制在 1 MB 内。
- 一次 8–12 张，文件名按 `01-XXX.png` 排序，上传顺序即文件名顺序。
- 封面（第一张）承担点击率：一句话结论 + 一张有质感的图。

## 文案：必须是纯文本

小红书正文**不解析 markdown**。`**加粗**`、`> 引用`、`- 列表` 都会原样显示成符号。

- 交付时用代码块包住可复制的标题与正文，并注明"直接复制"。
- 层次靠换行、空行和小节符号（`▍`、`—`）做，不靠 md 语法。
- 标题 ≤ 20 字，三个备选；正文含标点 ≤ 1000 字。
- 话题标签放正文末尾或发布时的标签栏。
- 正文字数够用时不要删信息，但也别为了凑字数重复正文里的句子。

## 合集

- 先判断笔记的**内容属性**再选合集，不要往"最接近的大筐"里塞。
- 与已有合集都不是一类时，新建一个。命名留出继续做的余地
  （「品牌视觉拆解」优于「美学拆解」，前者能容纳后续几期）。
- 合集定位被稀释的代价是以后自己也找不到。

## 发布后要改图

已发布笔记可以编辑，但有三条边界：

1. **图片张数锁死**，只能替换/裁剪，不能增删。所以出图时张数就定好。
2. **编辑次数有上限**（约 3 次），一次改到位，别拿它试错。
3. 保存后**重新过审**，几分钟内刷不出新图是正常的。

进编辑页要**点图片本身**去替换，点那个 `+` 会变成新增图片，张数超限直接报错。

刚发布、还没有流量和互动时，优先编辑而不是删了重发——
重发会丢掉正式发布时间，短时间内同账号重发一批高度相似内容还有被判重的风险。

## 素材与署名

- 引用他人的作品（广告片、设计、截图）时在末页标注来源与是否加工，
  并说明非商业用途。不要只写"侵删"。
- 转述数据、色值、参数这类信息时注明出处与查阅日期。
